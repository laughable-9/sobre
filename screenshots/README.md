## How to capture

1. Open the URL in a browser, give it ~2 seconds to load the contract details + recent transactions.
2. Screenshot the full page (or at minimum the header showing the contract address + Soroban label + creation tx).
3. Save as `screenshots/mainnet.png` or `screenshots/testnet.png` in this folder.
4. `git add screenshots/<name>.png && git commit -m "docs: add <network> deploy screenshot"`.

Both images will then render inline in the README's Deployment section.
